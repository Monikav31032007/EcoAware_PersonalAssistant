# Eco-Aware Personal Assistant

## Project Objective
Develop an AI/ML system that monitors air pollution, analyzes environmental data, and provides eco-friendly suggestions.

## Week 1: Data Collection & Preprocessing
- Created a simulated AQI dataset (30 days hourly)
- Preprocessed missing values
- Feature engineering: Month, Day, Hour
- Visualized AQI trends and distribution
- Saved processed dataset for Week 2 ML model

## Folder Structure
- Week1_Data_Preprocessing.ipynb : Notebook with all code and outputs
- processed_air_quality.csv : Cleaned dataset
- requirements.txt : Python libraries used
